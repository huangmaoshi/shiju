### 1.2 与「旧版规划」的差异说明

| 旧规划 | 实际实现 | 原因 |
|---|---|---|
| Vue 3 + Element Plus 管理后台 | **React 18 + Ant Design 5** | 开发时选了 React，生态更熟 |
| Redis | **未引入** | MVP 阶段无热数据缓存需求，SQLite 足够 |
| Bree 队列调度 | **node-cron 直接调度** | 任务简单（定时触发一次 HTTP import），不需要队列并发 |
| Puppeteer 抓 JS 动态页 | **后端内置 GitHub Raw JSON 直导入** | 数据源 99% 是 GitHub 上的静态 JSON 文件 |
| 独立 `crawler/` 进程做全部采集 | **后端内置 github_import_service + cron_service** | 独立进程增加运维复杂度，后端内置已能满足 |
| 采集速率限制（QPS）| **超时 + 重试 + 中文路径编码** | GitHub Raw 是静态文件，不需要 QPS 限制；真正需要的是网络容错 |
| AI 审核（敏感词 + AI 接口）| **审核流程：采集/AI 提取默认待审，人工批量审核** | 简单可靠，避免误杀优质内容 |
| Redis List 做采集队列 | **未引入** | 定时任务按需触发，不需要队列 |

## 四、核心模块技术实现

### 4.1 分级去重引擎

**文件**：`server/src/utils/dedup.ts`

**核心思想**：短文本用 MD5 精确匹配（快速、零误判），长文本用 SimHash 相似度（能识别"意思一样但措辞不同"的重复），双重比对正式库 + 采集临时库。

#### SimHash 算法流程

```
输入：一段文本内容
  │
  ▼
① 分词：中文用 2-gram（双字切分），英文按单词
   "愿得一心人" → ["愿得", "得心", "一心", "心人"]
  │
  ▼
② 哈希：每个 token 做 MD5，取前 64 位为该 token 的 64 位哈希
  │
  ▼
③ 加权：每个 token 的 64 位逐位累加（出现几次就加几次）
  │
  ▼
④ 降维：每一位 > 0 → 1，≤ 0 → 0
   → 得到 64 位 SimHash 指纹
  │
  ▼
⑤ 汉明距离：两个 64 位指纹逐位比较，不同的位数即为汉明距离
   汉明距离 ≤ 10 → 相似度 > 85% → 判定为重复
```

#### 去重引擎公开 API

```typescript
import dedup from "@/utils/dedup";

// 计算单个指纹
const fp = dedup.fingerprint("愿得一心人，白首不相离");
// → { contentMd5: "a1b2c3...", simHash: "101101...0101" }

// 判断是否重复
const isDup = dedup.isDuplicate(newFp, existingFps);

// 默认阈值
dedup.DEFAULT_SIMHASH_THRESHOLD; // 汉明距离 ≤ 10
dedup.SHORT_TEXT_LEN;            // 100 字（短文本跳过 SimHash）
```

#### 双重比对调用链

```
github_import_service.importFromGithubRaw()
  │
  ├─ fetchWithRetry()  ← 30s 超时 + 3 次重试 + 中文路径 URL 编码
  │
  ├─ parseJson()       ← 自动识别 { content } / { paragraphs:[] } / { author: "作者" } 等多种 JSON 格式
  │
  ├─ loadExistingStores()
  │   ├─ prisma.originalText.findMany({ select: { contentMd5: true, simHash: true } })
  │   ├─ prisma.quote.findMany({ select: { contentMd5: true, simHash: true } })
  │   └─ prisma.crawlRecord.findMany({ select: { simHash: true, content: true } })
  │
  └─ for each record:
      ├─ dedup.fingerprint(content) → { contentMd5, simHash }
      ├─ 批次内 MD5 命中？ → 跳过
      ├─ 正式库 MD5 命中？ → 跳过
      ├─ simHash 非空 + 与已有 simHash 比对？ → 相似度 > 85% → 跳过
      └─ 都没命中 → prisma.originalText.create({ data: { ..., auditStatus: 0 } })
```

### 4.2 GitHub Raw 直导入（带超时重试）

```typescript
const FETCH_TIMEOUT_MS = 30_000;     // 30 秒超时
const MAX_RETRIES = 3;               // 最多 3 次重试
const RETRY_DELAY_MS = 1500;         // 初始等待时间，后续递增

async function fetchWithTimeout(url, timeoutMs) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeoutMs);
  try {
    return await fetch(url, {
      headers: { "User-Agent": "ShiJu-Crawler/1.0" },
      signal: controller.signal,  // ← 超时自动中断
    });
  } finally {
    clearTimeout(timer);
  }
}

async function fetchWithRetry(url) {
  for (let attempt = 1; attempt <= MAX_RETRIES; attempt++) {
    try {
      const resp = await fetchWithTimeout(url, FETCH_TIMEOUT_MS);
      // 404 直接返回失败（重试没意义）
      if (resp.status === 404) return { ok: false, error: "HTTP 404 资源不存在" };
      // 客户端错误（4xx）直接返回
      if (resp.status >= 400 && resp.status < 500) {
        return { ok: false, error: `HTTP ${resp.status}: ${await resp.text().slice(0, 200)}` };
      }
      // 成功返回文本
      if (resp.ok) return { ok: true, text: await resp.text() };
      // 5xx 或网络错误 → 重试
    } catch (err) {
      // AbortError = 超时；其他 err.cause.code = ECONNRESET / ENOTFOUND 等
    }
    // 指数退避
    if (attempt < MAX_RETRIES) {
      await new Promise(r => setTimeout(r, RETRY_DELAY_MS * attempt));
    }
  }
  return { ok: false, error: `${lastError}（重试 ${MAX_RETRIES} 次仍失败）` };
}
```

**URL 拼接（admin_controller.resolveGithubRawUrl）**：

```typescript
// remark = "chinese-poetry/chinese-poetry/master/全唐诗/poet.tang.0.json"
// baseUrl = "https://raw.githubusercontent.com"

// 1. 正则放宽：支持中文字符 \u4e00-\u9fa5
const regex = /^[\w.\-\u4e00-\u9fa5%]+\/[\w.\-\u4e00-\u9fa5%]+\/.+$/;

// → https://raw.githubusercontent.com/chinese-poetry/chinese-poetry/master/%E5%85%A8%E5%94%90%E8%AF%97/poet.tang.0.json
```

### 4.3 Cron 定时采集调度器

**文件**：`server/src/services/cron_service.ts`

**启动入口**：`server.ts` 最后一行：

```typescript
// server.ts 启动流程
console.log("🚀 拾句后端启动: http://localhost:" + PORT);

```

**核心实现**：

```typescript
import cron from "node-cron";

class CronScheduler {
  private tasks = new Map<number, cron.ScheduledTask>();

  async startAll() {
    // 从 DB 读取所有启用的调度
    const schedules = await prisma.crawlSchedule.findMany({ where: { enabled: 1 } });
    
    for (const sched of schedules) {
      this.register(sched.sourceId, sched.cronExpr);
    }
    console.log(`[CronScheduler] loaded ${schedules.length} schedules`);
  }

  register(sourceId: number, cronExpr: string) {
    const task = cron.schedule(cronExpr, async () => {
      try {
        await prisma.crawlSchedule.update({
          where: { sourceId },
          data: { lastRunStatus: "running", lastRunAt: new Date() },
        });
        // 直接调用 admin_controller 的 crawlImport 逻辑
        const result = await importFromGithubRaw({ sourceId, ... });
        await prisma.crawlSchedule.update({
          where: { sourceId },
          data: {
            lastRunStatus: "success",
            lastRunCount: { increment: result.totalInserted },
            nextRunAt: this.computeNextRunTime(cronExpr),
          },
        });
      } catch (err) {
        await prisma.crawlSchedule.update({
          where: { sourceId },
          data: { lastRunStatus: "failed", lastError: String(err) },
        });
      }
    }, { timezone: "Asia/Shanghai" });

    this.tasks.set(sourceId, task);
  }

  // 支持启停
  stop(sourceId: number) { this.tasks.get(sourceId)?.stop(); }
  restart(sourceId: number, cronExpr: string) { /* 先 stop 再 register */ }

  // 立即执行（不等 Cron 到点）
  async runNow(sourceId: number) { /* 直接调 importFromGithubRaw */ }
}
```

### 4.4 AI HTTP 客户端（统一 OpenAI 协议）

**文件**：`server/src/utils/ai_client.ts`

**设计思路**：不管 Provider 是什么，只要它兼容 OpenAI 的 `/chat/completions` + Bearer Token 协议，就能用同一个客户端。

```typescript
interface AiCallOptions {
  baseUrl: string;         // 如 "https://ark.cn-beijing.volces.com/api/v3"
  apiKey: string;
  model: string;           // 如 "doubao-1-5-pro" 或 "ep-xxxxxxxxxx-xxxxx"
  messages: Array<{ role: "system" | "user" | "assistant"; content: string }>;
  temperature?: number;
  maxTokens?: number;
  timeoutMs?: number;      // 默认 60 秒（AI 响应可能较慢）
}

async function callChatCompletions(opts: AiCallOptions): Promise<string> {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), opts.timeoutMs ?? 60_000);

  try {
    // 统一拼 URL：去掉尾部 /chat/completions 避免重复
    const base = opts.baseUrl.replace(/\/+$/, "").replace(/\/chat\/completions$/i, "");
    const url = `${base}/chat/completions`;

    const resp = await fetch(url, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${opts.apiKey}`,
      },
      body: JSON.stringify({
        model: opts.model,
        messages: opts.messages,
        temperature: opts.temperature ?? 0.7,
        max_tokens: opts.maxTokens ?? 2048,
      }),
      signal: controller.signal,
    });

    if (!resp.ok) {
      const body = await resp.text().catch(() => "");
      throw new Error(`AI 请求失败 HTTP ${resp.status}: ${body.slice(0, 300)}`);
    }

    const data = await resp.json();
    return data.choices[0].message.content as string;

  } finally {
    clearTimeout(timer);
  }
}
```

### 4.6 原文选段一键加金句

**交互**：用户在 `OriginalTextDetail.tsx`（原文详情页）选中任意文本 → 前端弹出浮动气泡「+ 加为金句」→ POST 到后端 → 后端自动算 MD5/SimHash → 入库。

**后端接口**：

```typescript
// POST /api/v1/admin/original-text/:id/extract-quote
// Body: { selectedText: string, author?: string, source?: string, summary?: string }

const quote = await prisma.$transaction(async (tx) => {
  // 1. 算指纹（用于去重）
  const fp = dedup.fingerprint(selectedText);

  // 2. 去重检查
  const dup = await tx.quote.findFirst({ where: { contentMd5: fp.contentMd5 } });
  if (dup) throw new Error("该选段已是金句");

  // 3. 创建金句
  const created = await tx.quote.create({
    data: {
      content: selectedText,
      contentMd5: fp.contentMd5,
      simHash: fp.simHash,
      author: author ?? original.author,
      source: source ?? original.title,
      originalTextId: original.id,
      quoteType: "admin",            // 标记为管理员手动添加（不去重）
      auditStatus: 1,                // 管理员手动添加默认通过
      wordCount: selectedText.length,
    },
  });

  // 4. 原文的 quoteCount + 1
  await tx.originalText.update({
    where: { id: original.id },
    data: { quoteCount: { increment: 1 } },
  });

  return created;
});
```
